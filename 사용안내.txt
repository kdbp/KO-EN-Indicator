KorEng v1.0.1 — Windows 11 영문 입력 표시

실행
dist 폴더의 KorEng.exe를 원하는 폴더에 놓고 실행하십시오.
별도 .NET 설치 없이 실행되는 Windows x64용 단일 실행파일입니다.
첫 실행에서 '작동'과 '윈도우 시작 시 자동 실행'이 켜집니다.
윈도우 로그인 후에는 설정 창을 띄우지 않고 트레이에서 시작합니다.

사용
영어 키보드 또는 한국어 입력기의 영문 모드에서 실제 입력 커서 바로 아래에 작은 A를 표시합니다.
한글 모드, 다른 언어 또는 상태와 위치를 확인할 수 없는 경우에는 숨깁니다.
A 표시는 입력 포커스를 가져가지 않으며, 마우스 클릭을 통과시킵니다.
설정 창의 최소화 또는 닫기를 누르면 트레이에 유지됩니다.
트레이 아이콘을 한 번 클릭하면 설정 창이 표시됩니다.
완전히 종료하려면 트레이 아이콘을 오른쪽 클릭하고 '종료'를 선택하십시오.
작동을 끄면 표시와 커서 감지용 보조 프로세스를 중지합니다.

호환 범위
표준 Windows 입력 커서와 Microsoft 접근성 기능으로 커서 좌표를 제공하는 앱을 지원합니다.
Windows 기본 커서, 접근성 커서, 화면 요소 자동화의 입력 범위를 순서대로 확인합니다.
탐색기의 빈 검색란은 글자를 입력하기 전에도 입력칸의 글꼴 크기와 화면 배율을 이용해 표시합니다.
탐색기 경로란에서 경로 전체가 선택된 상태도 입력 커서의 활성 끝을 확인하여 표시합니다.
그 외에 커서 위치를 확인할 수 없는 경우에는 마우스 위치나 입력창 전체 위치로 대신 표시하지 않습니다.
브라우저·편집기마다 빈 입력칸, 줄바꿈 경계, 읽기 전용 화면의 지원이 다를 수 있습니다.
일부 비밀번호 입력칸은 접근성 경로에서 제외됩니다.
테두리 없는 전체화면도 해당 게임이 입력 커서 정보를 제공할 때만 표시할 수 있습니다.
독점 전체화면 게임, 자체 그리기 커서, 보호된 게임, 잠금·권한 승인 화면,
관리자 권한 앱, 접근성을 제공하지 않는 앱의 동작은 보장하지 않습니다.
프로세스 주입·게임 후킹·관리자 권한 강제 실행은 사용하지 않습니다.
실제 브라우저와 게임 전체의 동작을 확인한 제품으로 표시하지 않습니다.

설정과 자동 실행
실행파일 옆 KorEng.settings.json에 작동 여부, 자동 실행 여부, 창 위치·크기를 저장합니다.
따라서 쓰기 가능한 폴더에 실행파일을 보관하십시오.
설정 파일은 실행 시 생성되는 데이터이며 배포용 추가 실행파일이나 라이브러리가 아닙니다.
자동 실행은 현재 사용자 레지스트리의 다음 값만 사용합니다.
HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run\KorEng
자동 실행 명령은 실행파일의 절대 경로와 --startup 옵션입니다.
작업 관리자의 시작프로그램에서 별도로 사용 안 함으로 지정하면 운영체제 설정이 우선합니다.
실행파일을 옮긴 뒤 새 위치에서 한 번 실행하면 자동 실행 경로도 갱신됩니다.

업데이트와 삭제
트레이에서 종료한 다음 같은 위치의 KorEng.exe를 새 버전으로 교체하십시오.
실행파일 이름과 경로를 유지하면 기존 바로가기와 자동 실행 경로가 유지됩니다.
이번 배포는 요청에 따라 별도 런처·업데이트 실행파일을 추가하지 않았습니다.
삭제 전 '윈도우 시작 시 자동 실행'을 끈 뒤 트레이에서 종료하고 실행파일과 설정 파일을 삭제하십시오.

개인정보 및 자원 사용
입력한 글자, 비밀번호, 창 제목, 문서, 클립보드, 브라우저 기록을 수집·기록하지 않습니다.
네트워크 통신, 자동 업데이트, 키보드 입력 기록, 화면 캡처 기능이 없습니다.
전경 창의 입력기 상태, 화면 요소의 상태와 커서 사각형만 일시적으로 사용합니다.
80밀리초 간격으로 가벼운 확인을 하며 접근성 확인은 최대 약 6회/초로 제한합니다.
느린 접근성 제공자는 별도 프로세스에서 확인하고 시간 초과 시 종료·재시도 대기를 적용합니다.
작동 시 작업 관리자에 같은 KorEng.exe가 보조 프로세스로 추가 표시될 수 있습니다.
.NET 단일 파일의 기본 실행 구성요소는 첫 실행 시 운영체제 임시 캐시에 풀릴 수 있습니다.
이는 입력 기록이나 사용자 파일 복사본이 아닙니다.

개발 및 검증
소스: 이 프로젝트 폴더의 C# 파일, KorEng.csproj, app.manifest
빌드: .NET 10 SDK가 설치된 환경에서 build.cmd를 실행하십시오.
빌드용 다운로드와 임시 파일은 프로젝트 안의 .build, bin, obj에 모입니다.
검증: KorEng.exe --self-test (직접 만든 시험 창만 표시하며 자동 실행 등록은 변경하지 않습니다.)
검증 결과는 실행파일 옆 test-results 폴더에 생성됩니다.
진단 옵션을 명시적으로 실행한 경우에만 탐색기의 좌표와 입력 상태를 최대 1분간 기록합니다.
일반 실행에서는 이 진단 기록을 생성하지 않습니다. 입력 글자와 폴더 경로는 진단에서도 읽지 않습니다.
단위·소유 시험 창 검증은 실제 한국어 입력기와 모든 브라우저·게임에서의 검증을 대신하지 않습니다.
