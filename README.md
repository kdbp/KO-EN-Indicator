# 한/영 입력 표시기 (KoEng Indicator)

**지금 입력기가 한글인지 영어인지, 커서 바로 아래에서 한눈에 알려주는 작은 윈도우 프로그램입니다.**

키보드로 글을 쓰다 보면 한/영 상태를 착각해 엉뚱하게 입력하는 일이 잦습니다. 이 프로그램은 **영어 입력 상태일 때만** 깜빡이는 커서 아래에 작게 `A` 배지를 띄워, 지금 상태를 즉시 확인할 수 있게 해줍니다.

---

## ✨ 주요 기능

- **커서 따라다니는 상태 표시** — 영어 입력 중일 때만 커서 아래에 작은 `A` 배지 표시 (한글일 때는 아무것도 안 뜸)
- **거의 모든 곳에서 동작** — 일반 창, 웹 브라우저, 입력창 대부분
- **작업표시줄 트레이 상주** — 창을 닫아도 트레이로 최소화되어 계속 동작
- **윈도우 시작 시 자동 실행** (선택) — 켜두면 부팅 시 조용히 트레이에서 시작
- **작동 On/Off 스위치** — 필요할 때만 잠깐 끌 수 있음
- **단일 실행파일** — 설치 불필요

---

## 🛡️ 안심하고 쓰셔도 됩니다 (개인정보 · 보안)

이 프로그램의 동작은 겉보기에 예민할 수 있어, 아래 내용을 투명하게 밝힙니다.

- **키 입력을 가로채거나 기록하지 않습니다.** 키로거가 아닙니다. 무슨 글자를 쳤는지는 전혀 보지 않습니다.
- **입력한 텍스트 내용을 읽지 않습니다.** 커서(캐럿)의 **위치와 높이(사각형 좌표)만** 조회해 그 아래에 배지를 그릴 뿐입니다.
- **네트워크 통신이 전혀 없습니다.** 어떤 데이터도 외부로 보내지 않고, 서버에 연결하지 않습니다.
- **관리자 권한을 요구하지 않습니다.** (`asInvoker` — 일반 사용자 권한으로만 실행)
- **수집·저장하는 개인정보가 없습니다.** 저장하는 것은 레지스트리의 설정값 2개(작동 On/Off, 자동 실행 여부)뿐입니다.
- **오픈소스입니다.** 모든 소스 코드가 이 저장소에 공개되어 있어 직접 확인·빌드할 수 있습니다.

### "Windows에서 PC를 보호했습니다" 경고가 뜨는 경우

이 프로그램은 **코드 서명 인증서가 없어** 처음 실행할 때 Windows SmartScreen이 *"알 수 없는 게시자"* 경고를 띄울 수 있습니다. 이는 악성 프로그램이라는 뜻이 아니라, **유료 인증서로 서명하지 않은 모든 개인 개발 프로그램에 공통으로 나타나는 안내**입니다.

실행 방법:

1. 경고 창에서 **[추가 정보]** 클릭
2. **[실행]** 버튼 클릭

> 백신이 오탐(false positive)을 낼 수도 있습니다. 불안하시면 소스 코드를 직접 확인하고 [직접 빌드](#-직접-빌드하기)해서 사용하시길 권장합니다.

## 🚀 사용법

1. [Releases](../../releases)에서 최신버전을 내려받습니다.
2. 실행하면 작은 설정 창이 뜹니다.
   - 위쪽 스위치: **작동 On/Off**
   - 아래쪽 스위치: **윈도우 시작 시 자동 실행 On/Off**
3. **닫기(X)** 또는 **최소화** 버튼을 누르면 프로그램이 종료되지 않고 **작업표시줄 트레이 아이콘으로 숨겨집니다.**
4. 다시 열려면 트레이의 파란 `한` 아이콘을 **더블클릭**합니다.
5. **완전히 종료**하려면 트레이 아이콘을 **우클릭 → [종료]** 를 선택합니다.

## ⚙️ 동작 원리 (기술 요약)

- **한/영 상태 판별**: 포그라운드 창의 IME에 `WM_IME_CONTROL`(`IMC_GETCONVERSIONMODE`)을 질의해, 한글(네이티브) 모드가 아니면 영어로 판단합니다.
- **커서 위치 추적**:
  1. 1차로 고전 시스템 캐럿(`GetGUIThreadInfo`)을 사용하고,
  2. 실패하면 **UI Automation**(`TextPattern`)으로 폴백해 새 메모장·브라우저·Electron 앱 등의 커서 위치를 얻습니다.
  3. 이때 **편집 가능한 입력 요소**에서만 배지를 표시하도록 걸러, 읽기 전용 웹 본문을 클릭했을 때 오작동하지 않게 했습니다.
- **표시**: 클릭이 통과되고(입력 방해 없음) 활성화되지 않는 **투명·최상위 오버레이 창**에 배지를 그립니다.

## 📌 알려진 한계

- **전용 전체화면(Exclusive Fullscreen) 게임** 위에는 표시되지 않을 수 있습니다. (일반적인 '테두리 없는 전체화면' 창에서는 대부분 동작)
- **관리자 권한으로 실행된 창**에서는 입력 상태 조회가 제한될 수 있습니다.
- 커서(캐럿) 정보를 전혀 노출하지 않는 일부 프로그램에서는 배지가 뜨지 않을 수 있습니다.

## 🧰 직접 빌드하기

[.NET SDK 10](https://dotnet.microsoft.com/download) (Windows)이 필요합니다.

```bash
# 저장소 클론 후
dotnet publish src/KoEngIndicator.csproj -c Release -o dist
```

`dist/한영표시기.exe` 단일 파일이 생성됩니다. (자체 포함 빌드라 .NET 런타임 설치가 필요 없습니다.)
